# program/

The artifacts a technical program manager keeps for a pilot like this one. Everything dated here
was written on the date shown; nothing is backdated.

| File | What it is |
|---|---|
| `CHARTER_case_triage.md`, `CHARTER_dispatch_readiness.md`, `CHARTER_fleet_health_reporter.md` | one charter per agent: problem, owner, success metric, stop criteria |
| `DECISIONS.md` | dated decision log (18 items), including every fallback taken and the closing decisions at v0.1 |
| `STATUS_2026-W42.md` | weekly status note: shipped, cut, risks, next steps if the pilot were real |
| `RUNBOOK.md` | how to operate the pilot (start, run, approve, rotate keys, recover) |
| `MEMO_case_triage.md`, `MEMO_dispatch_readiness.md`, `MEMO_fleet_health_reporter.md` | one page each: what the pilot proved, with the numbers from `reports/` |
| `../reports/cost.csv`, `../reports/cost.png` | cost dashboard: tokens and dollars per task per model, from the audit log |
