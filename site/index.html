knowledge-agents-pilot

Three governed Knowledge Agents that do Services Operations work on top of NVIDIA Auto Ontology, Elasticsearch and MCP, each with the evaluation, cost record and program paperwork a technical program manager needs to decide whether to scale it.

Repository on GitHub README reports/ (the source of every number here) program/
Realthe drive telemetry under everything (Backblaze 2026 Q2 via the sibling project), the 30-day risk scores from its model, NVIDIA Auto Ontology, the models, the latencies and token counts.
Generatedaccounts, sites, assets, cases, dispatches, parts, inventory, technicians and runbooks, seeded with ground truth; case text is templated. Dollar costs on NIM are not real: the free developer tier bills nothing, so those rows say $0 and report tokens.
What is live here. This page is static: scripts/build_site.py reads reports/ and program/ and writes the JSON the charts draw from. Elasticsearch, Postgres, the MCP server, the agents and NVIDIA Auto Ontology do not run on Vercel. From a clone, make up && make load && make index brings up the stack, and make eval && make agent-eval && make search-eval && make cost reruns every evaluation from the committed model-response cache.

30 questions (10 easy, 10 medium, 10 hard, where a business definition decides the answer), one repair turn per arm, scored by execution match (set of gold rows equals set of predicted rows). The ontology arm is the same prompt plus the glossary, so the delta is the semantic layer's.
